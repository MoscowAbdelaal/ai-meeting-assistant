# AI Meeting Assistant

AI-powered tool that extracts summaries, decisions, and action items from meeting transcripts.

## Quick Start

```bash
# Clone and setup
git clone https://github.com/MoscowAbdelaal/ai-meeting-assistant.git
cd ai-meeting-assistant

# Backend
cd backend
npm install
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm start
Concepts

Concept	Location
API endpoints	/backend/src/routes/
Database	PostgreSQL
Authentication	Supabase Auth
Background jobs	Inngest cron
LLM integration	OpenRouter
Reporting	Playwright PDF
Caching	In-memory cache
